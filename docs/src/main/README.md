# Getting Started

This is the main Documentation website for APICRUON, it is divided into two section, Developer Documentation and General Guide.

- The [Developer Documentation](/dev/) is aimed at explaining how APICURON works for Developers and interested organizations 
who might be interested in integrating APICURON with their resource

- The [General Guide](/main/guide/) is aimed at explaining how APICURON can benefit curators and contributos of organizations
that use APICURON and elaborates on how the tool works
