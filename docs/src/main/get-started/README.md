

# Introduction

**APICURON** is a Webserver that can allow you to **recognize contributions** to your resource which can be a Database, Registry or a Respository any identifiable using URI can be a Resource.


Current **APICURON** implementation is geared towards **scientific resources** and offers representations and tools that can help you integrate easily like [ORCID](https://orcid.org) to identify curators and reward them.

a good starting point to integrate your Resource is visiting the [Getting Started Page](/main/get-started/getting-started)
