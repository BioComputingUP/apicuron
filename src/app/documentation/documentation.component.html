Report biocuration activity

Purpose
Report biocuration event.
Query
POST query with a singe JSON object.
Return
Return message

Query Parameters

Field Example value Availability Description
curator_orcid 0000-0002-0341-4888 Mandatory ORCID of the data resource contributor
resource_uri disprot Mandatory Identifier of the reporting resource
timestamp 2020-02-11T09:32:10.928Z Mandatory Time point of the biocuration event.
entity_uri https://identifiers.org/disprot.region:DP02359r003 Mandatory URI of the biocurated entity, preferable to use identifiers.org
activity_term entry_cereated_by_homology Mandatory Description of the biocuration activity codified by resource specific controlled vocabulary under /resource_registration endpoint .

Query Parameters

Field Example value Availability Description
resource_uri https://registry.identifiers.org/registry/disprot Mandatory
scoring_table See blow Mandatory A list of objects representing APICURON scoring table activity terms

Scoring table
Field Example value Availability Description
activity_category Mandatory The category should be Generation , Revision or Invalidation form PROV ontology
activity_term Mandatory
score 80 Mandatory Gamification score given by biocuration activity.
Badges table
Field Example value Availability Description
count_threshold Optionally (One of optional field is mandatory) Who reach the minimum threshold of the count of the selected activity terms earn the badge.
score_threshold Optionally (One of optional field is mandatory) Who reach the minimum threshold of the sum of the selected activity terms earn the badge.
count_relative Optionally (One of optional field is mandatory) The best biocurators (number as a percentage), calculated from the count of selected activity terms
score_relative Optionally (One of optional field is mandatory) The best biocurators (number as a percentage), calculated from the sum of the selected activity terms
list_terms Mandatory The selected activity terms.
badge_name Mandatory The name of the badge.
first_day Optional The earliest day, which is considered by the calculation of the badge.
last_day Optional The latest day, which is considered by the calculation of the badge.
