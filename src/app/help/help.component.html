Web interface

This page describes APICURON website use. For information about API endpoints and the output format see the next section.

The APICURON graphical user interface allows easy access to the biocuration activities of our partner databases in a graphical way. Biocurators can be searched from the Curators page or from the search box on the Home page.

Databases page

The Databases page lists all member databases registered to APICURON. Member databases periodically push curation activities and APICURON synchronously calculates achievements and leaderboards.

Database specific page

By clicking on a card in the Databases page, you get redirected to a page dedicated to a specific resource.
  1. Database description as provided by the database project manager
  2. Leaderboard the ranking of curators based on the total amount of curation activities weighted by the corresponding score
  3. Available badges and the corresponding definition
  4. Available medals and the corresponding definition
  5. Curation activity records the full list of curation activities submitted to APICURON

Curators page

The Curators page is composed of a result table, a sidebar and a search bar.
  • Table By default it shows the first entries of the database sorted alphabetically. You can change the table sorting by clicking on column headers.
  • Search box It offers a free text search against all entry values. Alternatively, it allows users to specify the field to search against, e.g. biocurator name, resource identifier, ORCID, etc.

Personal profile page

By clicking on a row of the curators table in the Curators page or from the search box in the Home page, you get redirected to the personal profile page of a biocurator. The profile page features different sections.
  1. Personal information name and ORCID
  2. Biocuration statistics number of generated/revised/invalidated entitities
  3. Achievements Badges and medals earned
  4. Biocuration events This section include a search bar (above) and a table (below) listing all the entity identifiers, activity terms and timestamps.

Public API

Reports (biocuration events or activities)

{{wsname}}reports
Purpose
Retrieve biocuration events (or activities)
Return
A JSON list of objects representing the biocurators and their activities. One object per event
Examples
{{wsname}}reports?curator_orcid={{curator_orcid}}&limit=2
{{wsname}}reports?resource_uri={{resource_uri}}&limit=2
Query parameters
Field Example value Description
curator_orcid {{curator_orcid}} Biocurator ORCID
curator_name Federica Quaglia Biocurator name
resource_uri {{resource_uri}} Resource unique identifier (URI)
date_from 2020-01-01 Event date from
date_to 2020-12-31 Event date to
Other parameters
Field Example value Description
limit 10 Number of items to return
skip 20 NUmber of items to skip (useful for pagination)
format tsv The output format. By default it returns a json stream. If explicitly format=json it returns a json file
Output format 
{{output["reports"] | json}}

Achievements (badges and medals)

{{wsname}}achievements
Purpose
Retrieve biocurators achievements in terms of badges and medals
Return
A JSON list of objects representing biocurators badges or medals
Examples
{{wsname}}achievements?curator_orcid={{curator_orcid}}&limit=2
{{wsname}}achievements?resource_uri={{resource_uri}}&limit=2
Query parameters
Field Example value Description
curator_orcid {{curator_orcid}} Biocurator ORCID
curator_name Federica Quaglia Biocurator name
resource_uri {{resource_uri}} Resource unique identifier (URI)
type badge The type of achievement, either "badge" or "medal"
min_count 200 Minimum number of curation events
Other parameters
Field Example value Description
limit 10 Number of items to return
skip 20 Number of items to skip (useful for pagination)
format tsv Output format. By default it returns a json stream. If explicitly format=json it returns a json file
Output format 
{{output["achievements"] | json}}

Leaderboards (biocurators ranking and scores)

{{wsname}}leaderboards
Purpose
Retrieve ranking and scores
Return
A JSON list of objects representing the biocurators ranking and scores. One object per biocurator and database
Examples
{{wsname}}leaderboards?curator_orcid={{curator_orcid}}&limit=2
{{wsname}}leaderboards?resource_uri={{resource_uri}}&limit=2
Query parameters
Field Example value Description
curator_orcid {{curator_orcid}} Biocurator ORCID
curator_name Federica Quaglia Biocurator name
resource_uri {{resource_uri}} Resource unique identifier (URI)
ranking badge Position in the global database ranking
min_total_score 2000 Minimum total score of a biocurator
Other parameters
Field Example value Description
limit 10 Number of items to return
skip 20 Number of items to skip (useful for pagination)
format tsv Output format. By default it returns a json stream. If explicitly format=json it returns a json file
sort generation_score Sorting field
Output format 
{{output["leaderboards"] | json}}

Private API

All private endpoints are only available to registered organizations and intended to be used only for submitting curation data. To become an APICURON member database and open an account to submit data please contact us at apicuron@ngp-net.bio.unipd.it

Submit description

{{wsname}}submit_description
Purpose
Submit resource setting and definition to APICURON. It takes the list and definition of activity terms and the corresponding scores. Badges and medals definitions and rules and a short text describing the resource
Return
A confirmation JSON objects
Request fields
Field Subfield Description
resource_uri This is the identifier used to identify the resource and activity terms (see submit activity)
resource_url Resource URL
resource_name Resource name
resource_long_name Resource full name
resource_description Text describing the resource shown in the APICURON database pages
terms_def The definition of an activity term. Each activity term has the following fields. See tables below
activity_term Activity term identifier
activity_name Activity term name
activity_category Activity term category. Either "generation", "revision" or "invalidation"
score An interger number representing the effort or importance of the curation activity
description A human readable description of the activity term
achievements_def The definition of achievements and parameters for their calculation. See tables below
type Either "badge or "medal"
category A number to identify a group of related badges/medals
name Human readable name of the badge/medal
list_terms The list of activity terms to be considered to assign the badge/medal
color The hexadecimal color code or color name used ot visualize the badge/medal. You can se gold/silver/bronze for a metal effect
count_threshold Only badges. The count threshold to assign the badge
score_relative Only medals. The ranking over other database curators to assign the medal. The ranking is calculated by multiplying the activities listed in "list_terms" with the corresponding score
first_day Only medals. Consider activity terms from this date
last_day Only medals. Consider activity terms to this date
Example 
{{submit['description'] | json}}

Submit activity

{{wsname}}submit_activity
Purpose
Submit curation activities to APICURON
Return
A confirmation JSON objects
Request fields
Field Description
resource_uri Unique resource identifier
reports The list of curation activity objects that are stored in APICURON
activity_term The curation activity term identifier
resource_uri The database identifier
timestamp The date and time of the curation activity
curator_orcid The ORCID identifier of the biocurator
entity_uri The identifier of the curated object in the source database
Example 
{{submit['activity'] | json}}

Delete activity

{{wsname}}delete_activity
Purpose
Delete curation activities to APICURON. Useful if some activities are submited by mistake or if the member database changes the tracked curation activities
Return
A confirmation JSON objects
Request fields

Same format of one object as defined in the "reports" field of the submit_activity endpoint
