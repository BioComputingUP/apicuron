Help

This section describes APICURON website use. For information about RESTful endpoints and the output format see the API documentation below.

Graphical User Interface (GUI)

The APICURON graphical user interface allows easy access to the biocuration activities of our partner databases in a graphical way. The data can be searched from the Browse page or from the search box in the Home page.

Browse page

The Browse page is composed of a result table, a sidebar (left) and a search bar (above the table).
  • The table lists search results. By default it shows the first 20 entries of the database sorted alphabetically by the PED identifier (second column). You can change the table sorting by clicking on column headers.
  • The sidebar allows users to select columns to visualize and customize the results of their search.
  • The search box right above the table offers a free text search against all entry values. Alternatively, it allows users to specify the field to search against, e.g. biocurator name, resource identifier, activity category. It is possible to combine multiple criteria and create complex queries with an intersection ("AND" operator).

Biocurator profile

By clicking on the name or the ORCID of a biocurator, users can access the profile of the biocurator. The profile of a biocurator features two different sections, described here from the top to the bottom:
  1. Biocurator details: here are available the contact info of the biocurator, i.e. name and ORCID, the number of biocuration entities belonging to the biocurator, i.e. entity generation, entity revision, entity invalidation, the contributed resources, e.g. DisProt, PED, and the badges associated with the biocurator.
  2. Contributions to biological databases: here are listed all the databases contributed by the biocurator. For example, by clicking on “Contribution in DisProt”, users will be able to visualize all the contributions of the biocurator to DisProt. This section include a search bar (above) and a table (below) listing all the entity identifiers, activity terms and timestamps.
