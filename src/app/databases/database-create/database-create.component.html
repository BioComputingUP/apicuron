Creating a Resource

To create a resource, you can use one of the following two options:

1. You can use our FairSharing integration. For this you need to insert Fairsharing DOI of the resource. Once the fairsharing entry is found, a popup will appear with the name of the resource curated from Farisharing. You can prefill the form below using the data from fairsharing.

2. You can create a new resource to add to APICURON using the form below.

The created resource is not public until it is validated by the APICURON team. You can contact us on apicuron@ngp-net.bio.unipd.it to request a validation. Make sure to let us know the ID and the name of your resource and the ORCID ID of the account you used here when you do so. Upon validation you can update the resource and push additional information.
